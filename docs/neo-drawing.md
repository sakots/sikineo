# neo本体の配置と描画

## 対象

Sikiの対象スレッドからneoを開き、描いた画像をSikiの投稿欄へ渡す。起動方法・添付契約・制約は[画像引き渡しの仕様](image-attachment.md)を参照。レスの送信は利用者がSikiで行う。

## neo本体の取得

利用者指定の配布元から次の2ファイルを取得し、プラグインフォルダ内へ配置する:

- [`neo/neo.js`](https://oekakibbs.moe/apps/neo/neo.js)
- [`neo/neo.css`](https://oekakibbs.moe/apps/neo/neo.css)

```text
sikineo/
├─ package.json
├─ dist/
├─ public/
└─ neo/
   ├─ neo.js
   └─ neo.css
```

取得・配置後は描画のための外部ネットワーク接続は不要。プラグインから本体の自動取得・更新は行わない。ファイルが欠けている場合は配置案内を表示し、配置後はページを再読み込みする。

neo本体はGit・配布アーカイブには含めない。配布URLは固定バージョンURLではないため、検証結果に記録したバージョンと手元のファイル先頭の表記を確認する。lz-stringについてのMIT表記をneo本体のライセンス指定とは扱わず、著作権表示は削除しない。

## 描画と保存

- `.neo-applet-paintbbs`と`Neo.params.paintbbs`で初期化し、描画サイズはSikiの添付先情報から取得する。5ch向けは500×250px。
- neo自身の「投稿」は隠し、`paintBBSCallback('check')`も`false`を返す。独立した画像引き渡しボタンでSikiへ渡し、送信は行わない。
- 描画画像は表示レイヤーを白背景へ合成したPNG。自動リサイズや非可逆変換はしない。
- 失敗時にも描画を残す。成功後も描画画面を勝手に閉じない。
- 一時保存・復元はneoの機能であり、確実な保存は保証しない。同じオリジンの描画画面は保存領域を共有するため、同時に開く画面は1つにする。
- 旧v0.2の300×300pxの保存領域は削除・移行しない。新しい添付用画面をポート57831へ分離し、旧ポート57830の保存を誤って異なるサイズへ復元しない。

## 対応環境

Siki 0.43.12の内部描画保存処理を利用する。別バージョンの互換性は保証しない。検証範囲は[画像引き渡しの仕様](image-attachment.md)とREADMEを参照。
