# sikineo

sikineoは、汎用掲示板ブラウザsikiで5chのお絵かき機能にneoを使うためのプラグインです。

## 現在の機能

- Sikiの5chスレッドからneo描画画面を開き、描いた画像をその投稿欄へ渡せます。描画サイズは500×250pxです。起動時に描画画面は開きません。
- プラグイン起動時に`127.0.0.1:57831`で描画ページを提供し、待受完了後に`plugin:sikineo:ready`を1回発火します。
- neo本体は別途配置します。取得元は利用者指定の[neo.js](https://oekakibbs.moe/apps/neo/neo.js)と[neo.css](https://oekakibbs.moe/apps/neo/neo.css)です。描画時の外部ネットワーク接続は不要です。
- 本文を置き換えたり、レスを自動送信したりしません。添付後の送信はSikiで行います。PNGファイルへの書き出しは対象外です。

Siki **0.43.12**の公式Linux版を隔離プロファイル・ヘッドレス環境で起動し、コマンドパレットからの起動、実マウス描画、投稿欄への画像引き渡し、本文・名前・メール欄の保持、別タブへの誤添付防止を確認しました。検証したローカルneoは**1.8.12**です。レスの送信、通常のデスクトップ表示、Windows・macOSは未検証です。

## 開発

TypeScriptとpnpmを使用します。検証環境はNode.js 26.12.1、pnpm 12.15.0です。

```sh
pnpm install --frozen-lockfile
pnpm test
pnpm build
```

`pnpm test`でもビルドを実行します。成果物は`dist/index.js`です。

## Sikiへの配置

1. `pnpm build`を実行します。
2. SikiのPlugin Directory配下に`sikineo/`を作り、`package.json`と`dist/`、`public/`をコピーします。実行時の依存パッケージはありません。
3. 指定配布元の`neo.js`と`neo.css`を取得し、`sikineo/neo/`へ配置します。本体はGit・配布物に含めません。
4. Sikiの設定のプラグイン一覧で`sikineo`を有効化し、Sikiを再起動します。

```text
plugins/
└─ sikineo/
   ├─ package.json
   ├─ dist/
   ├─ public/
   └─ neo/
      ├─ neo.js
      └─ neo.css
```

配布アーカイブは`pnpm pack`で作成できます。アーカイブ内の`package/`の内容を上記の`sikineo/`へ配置してください。フォルダ名は`sikineo`に揃えます。

## 描画画面を開く

Sikiの設定の「ユーザーコマンド」で以下を追加します。

| 項目 | 値 |
| --- | --- |
| 名前 | `sikineo.open` |
| 表示名 | `neoで描く` |
| 実行コマンド | `uri:open-browserview` |
| 第1パラメータ | `http://127.0.0.1:57831/` |

対象スレッドを開き、コマンドパレット（標準では`Ctrl+Shift+P`）から「neoで描く」（`user:sikineo.open`）を実行します。描画画面の添付先を確認してから「Sikiの投稿欄へ画像を渡す」を押してください。画像はまだ送信されません。neo本体が未配置なら配置案内を表示します。

描画開始時の添付先を固定します。別タブへ切り替えても添付先は変わらず、対象タブを閉じた場合はエラーにします。詳細は[画像引き渡しの仕様](docs/image-attachment.md)を参照してください。

ポート57831が使用中なら待受は失敗します。旧v0.2のポート57830から変更することで、300×300の一時保存を新サイズに誤復元しないよう分離しています。旧保存データは削除・移行しません。neoの一時保存は確実な保存を保証しないため、描画画面は1つにしてください。

取得先・配置・制約・検証結果は[neo描画画面の資料](docs/neo-drawing.md)を参照してください。

配置先のOS別パスと読み込み契約は[実装資料](docs/plugin-loading.md)、ホスト側の仕様は[Siki公式資料](https://sikiapp.net/plugin-development/)を参照してください。

## 更新履歴

### [2026/11/05] v0.3.0

- neoで描いた画像をSikiで投稿できるよう、対象スレッドの投稿欄へ画像を渡す機能を追加。
- 別スレッドへの誤添付を防ぐため、描画開始時の対象を固定し、対象タブを閉じた場合は引き渡しを拒否する機能を追加。
- 旧版の一時保存を異なるサイズへ誤復元しないため、500×250pxの添付用画面をポート57831へ分離するよう修正。
- 不正な画像引き渡しを防ぐため、Origin・セッション・受信サイズの検証と回帰テストを追加。

### [2026/11/05] v0.2.0

- Sikiから手動で描画画面を開くため、ループバックHTTP配信とneo描画画面の機能を追加。
- neo本体を別途配置して利用するため、指定配布元の`neo.js`・`neo.css`の配置案内を追加。
- 描画専用であることを明確にするため、投稿操作を無効化し、保存上の制約を表示するよう修正。
- 想定外のファイル配信を防ぐため、HTTPの配信境界のテストを追加。

### [2026/11/05] v0.1.0

- Sikiの汎用プラグインとして読み込むため、TypeScript製の起動処理とCommonJSビルドの機能を追加。
- 読み込み時の問題を検出するため、起動通知のテストと配布物の検証手順を追加。

### [2026/11/05] v0.0.0

- リポジトリ生やした
